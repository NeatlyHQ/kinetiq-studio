Yes. There is no subscription, no renewal, no recurring charge. You pay once for the tier you choose and the file is yours to keep and use going forward.

Do I need an account or internet connection to use it?

No account is required to use the tool. It runs as a local file in your browser — your script and exported video never leave your computer.

What happens if NeatlyHQ stops updating the product?

The tool keeps working. It doesn't depend on a live server to render or export video, so there's nothing that can be shut off.

Which browsers are supported?

MP4 export requires a browser with WebCodecs support — Chrome or Edge on desktop. Native MP4 export is not available on Safari, Firefox, or mobile browsers.
